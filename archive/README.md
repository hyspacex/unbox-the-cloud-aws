# Archive

Earlier directions and prototypes, kept for history. None of this is part of the Keel app, and none of it is
maintained. The main experience is the Next.js app in [`app/`](../app/); see the [root README](../README.md).

Links inside these files point at their old locations and may be broken.

| Path | What it was |
| --- | --- |
| `desktop-client/` | Windows and macOS desktop HUD (Electron, or Python Tkinter with a local topic broker). It never called the Keel API, and its "COMPLIANT" / "UNMET" labels predate the app's wording rules |
| `demo/epistemicbox-prototype.html` | Interactive prototype for idea #2, EpistemicBox (agreement drift across proposal revisions). Was `demo/index.html` |
| `demo/keel.html` | Standalone Keel explainer page built before the app, from `docs/research/40-html-brief.md` |
| `docs/one-pager.md` | Idea #1, Epistemic Review (de-slopping AI-written docs) |
| `docs/idea-selection.md` | Comparison of the three ideas against the judging rubric |
| `docs/idea3-discussion.md` | Idea #3 discussion transcript |
| `docs/idea-evolution.md` | EpistemicBox's V1 to V3 history |
| `docs/research/10-*`, `11-*`, `12-*` | Keel design v1 and its Codex and persona reviews |
| `docs/research/20-*`, `21-*`, `22-*` | Keel design v2 and its Codex and persona reviews |
| `docs/research/40-html-brief.md` | Brief for `demo/keel.html` |
